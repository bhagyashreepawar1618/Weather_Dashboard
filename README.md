# 🌤 Weather Dashboard App

A  **Weather Dashboard Application** built using **Core HTML, CSS, and JavaScript** with real-time weather data fetched from a public Weather API.

This project allows users to search any city and view live weather information instantly.

## 🛠 Tech Stack

- CSS3

## 🌎 API Integration

- Fetch API used to request real-time weather data
- Dynamic data rendering on UI
- Async/Await for API calls

---

## ✨ Features

- 🔍 Search weather by city name
- 🌡 Displays current temperature
- 🌥 Shows weather condition (Cloudy, Clear, Rain, etc.)
- 💨 Wind speed display
- 💧 Humidity level

## ⚙ How It Works

1. User enters a city name.
2. JavaScript sends request to Weather API.
3. API returns JSON data.
4. Data is dynamically updated in the UI.
5. Weather details are displayed instantly.
